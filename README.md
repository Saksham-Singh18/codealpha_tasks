# Tasks Completed

## Task 1: Student Grade Tracker

A Java application that allows users to input and manage student grades.
The program calculates the **average, highest, and lowest scores** and displays a summary report.

**Features**

* Input student names and marks
* Calculate average score
* Find highest and lowest marks
* Display student grade summary

**Technologies Used**

* Java
* Arrays / ArrayLists
* Basic statistics calculations

---

## Task 2: Stock Trading Platform

A Java-based simulation of a **basic stock trading environment** where users can buy and sell stocks and track their portfolio.

**Features**

* Display available market stocks
* Buy and sell stocks
* Track portfolio holdings
* Monitor account balance

**Technologies Used**

* Java
* Object-Oriented Programming
* HashMap and ArrayList

---

## Task 3: Artificial Intelligence Chatbot

A Java-based **AI chatbot with a graphical user interface** that interacts with users and responds to questions using rule-based Natural Language Processing techniques.

**Features**

* Interactive chatbot interface
* Rule-based NLP response system
* Frequently asked question handling
* GUI using Java Swing

**Technologies Used**

* Java
* Java Swing
* HashMap
* NLP keyword matching
